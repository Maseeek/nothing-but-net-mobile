# State Update Skill

When you complete a task or need to record progress, follow these steps:

1. Identify the current active phase directory in `phases/`.
2. Open the `README.md` or `state.md` file in that directory.
3. Append a brief summary of the completed work.
4. If a phase is fully completed, document the decision to move to the next phase and notify the user to review before proceeding.
