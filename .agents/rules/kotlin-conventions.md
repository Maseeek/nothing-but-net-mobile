# Kotlin Best Practices

1. Follow standard Kotlin idiomatic patterns.
2. Favor immutability (`val` over `var` where possible).
3. Use coroutines for asynchronous operations.
4. Ensure code is well-documented, keeping in mind this is for a coursework project where code readability is graded.
