# KOTLIN MOBILE APP COURSEWORK STATUS

## System Overview

Building a mobile application for university coursework.

Architecture: Interpretable Context Methodology (ICM) relying on the file system (`phases/` directory) for state management.
Language: Kotlin
Platform: Mobile (Android)

## Standard of Quality

Student-Level Code: Ensure the code demonstrates a solid understanding of fundamental mobile development concepts (e.g., MVVM, concise UI development). Avoid overly complex abstractions unless required by the coursework. Code must be highly readable and well-documented.

UI/UX: Must be clean, responsive, and follow standard mobile design guidelines (Material Design). 

Tone: Concise, direct, and no fluff.

## Strategic Priorities

- **Mark Maximization**: All development must be optimized for the [marking criteria](../../resources/25COB155_CW_Specification.md).
- **Spec Adherence**: Strict adherence to mandatory technical requirements as defined in [SPECIFICATION_ADHERENCE.md](./SPECIFICATION_ADHERENCE.md).

## Recent Updates

- Adopted Folders-as-State (ICM) architecture to manage project progression through the `phases/` directory.
- Defined explicit rule for specification adherence and mark optimization.
